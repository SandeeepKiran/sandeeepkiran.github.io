# sandeeepkiran.github.io

Personal site of Sandeep Kiran, Senior QA Engineer at SoundHound AI.

Live at **https://sandeeepkiran.github.io**

- Plain HTML and CSS in one file (`index.html`), no build step.
- Three colour themes: dark, light and mondstadt (a teal-green gradient). The choice is saved in the browser.
- Layout inspired by [jonny.li](https://jonny.li/), used with his permission.
