# Sandeep Kiran's Portfolio

Live at **https://sandeeepkiran.github.io/**

This repo is a small **switch**. The designs live in
[Mousy-Portfolio](https://github.com/SandeeepKiran/Mousy-Portfolio), one design per branch.
This repo picks which design is shown at the main address.

| Link | Shows |
|---|---|
| https://sandeeepkiran.github.io/ | the Mousy-Portfolio branch named in [`live.txt`](live.txt) |
| https://sandeeepkiran.github.io/&lt;branch&gt;/ | any Mousy-Portfolio branch, for example `/david/` or `/jonny/` |

## Switch the design

1. Open [`live.txt`](live.txt).
2. Click the pencil icon (Edit).
3. Replace the word with a Mousy-Portfolio branch name, for example `david`.
4. Click **Commit changes**.

The site updates in about a minute (see the **Actions** tab).

## When does a change in Mousy-Portfolio show up here?

Within an hour: this repo rebuilds every hour. To update right away, open **Actions** →
**Deploy from Mousy-Portfolio** → **Run workflow**.
